# bookbot

BookBot is my first [Boot.dev](https://www.boot.dev) project!

This is a bot that will take an input of text(s) (currently based off a handful of selected free-domain books) and present:
- The number of words that appear in that text
- A descending sort of the alphabetic characters and their counts

With this information, I will one day:
- Have some use for the phrase "the quick brown fox jumps over the lazy dog"
- Know how many times the letter 'e' appears in my birthday card (zero, no input found)
- Rule the world
